## Reflection

1. Why should the fields be private?

The fields should be private because some apply to
one class while not applying to others, so making them
private prevents a vehicle having invald functions.

2. What happens if the Car constructor does not call super(...)?

If super is not called in the car constructor, then the functions made in the vehicle class will not apply to the constructor.

3. What is the difference between this.type and super.type?

"this.type" refers to the type establish in the current class while "super.type" refers to the type established in the parent class.
